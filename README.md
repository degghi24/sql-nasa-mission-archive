# NASA Mission Archive — Relational Database & C Client

An academic database project developed for the **Databases** (*Basi di Dati*) course at the **University of Padua** (A.Y. 2025/2026). The system is designed and implemented in **PostgreSQL** to model, store, and query structured data regarding space missions, programs, launch sites, vehicles, astronauts, and scientific payloads, and includes a **C command-line client** powered by `libpq` for direct database interaction.

> **Language Note:** While this documentation is in English, the accompanying academic report, schema identifiers, and SQL scripts are written in Italian.
